# ARRAYS Y CLASS
--

1. ## Repaso de algoritmos

Se revisó el concepto de algoritmo como una secuencia de instrucciones ordenadas que permiten resolver un problema o realizar una tarea específica.
Se destacaron características como precisión, orden, finitud y definición.

2. ## Estructura de un algoritmo

Se explicó que todo algoritmo está compuesto por:
Input (Entrada): información necesaria para comenzar.
Proceso: pasos que transforman la información.
Output (Salida): resultado final obtenido.

3. ## Diagramas de flujo

Se aprendió que los diagramas de flujo son representaciones gráficas de algoritmos.
Permiten planificar y visualizar la lógica de un programa antes de escribir código.
Utilizan símbolos estándar para representar procesos, decisiones e información.

Se analizaron diagramas que muestran cómo funcionan programas interactivos mediante decisiones y condiciones.
Estos ejemplos ayudaron a comprender la relación entre la lógica del programa y su implementación en código.

4. ## Arrays (listas)

Se introdujo el concepto de array, una estructura que permite almacenar múltiples datos bajo un mismo nombre.
Los arrays funcionan como una lista ordenada donde cada elemento posee una posición o índice.

5. ## Uso de arrays en p5.js

Se aprendió a crear arrays mediante corchetes [].
También se revisó cómo acceder a cada elemento utilizando su índice.
Los arrays permiten organizar y gestionar grandes cantidades de información de manera más eficiente.

6. ## Class (clases)

Se presentó el concepto de class como un molde o plantilla para crear objetos.
Una clase define las propiedades y comportamientos que tendrán los objetos creados a partir de ella.

7. ## Estructura de una clase

Se revisó la sintaxis básica de una clase en JavaScript:
Declaración de la clase.
Método constructor.
Funciones o métodos personalizados.
También se explicó el uso de this para definir propiedades de cada objeto.

8. ## Implementación de clases

Se aprendió dónde debe ubicarse una clase dentro del código.
Las clases se escriben fuera de setup() y draw(), se crean en setup() mediante new y sus métodos se ejecutan desde draw().

9. ## Combinación de Class + Array

Se trabajó la relación entre arrays y clases para crear múltiples objetos de manera eficiente.
Esta combinación permite generar sistemas más complejos, como partículas, personajes o elementos interactivos, gestionándolos a través de un solo array.
