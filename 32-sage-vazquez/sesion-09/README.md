# CÓMO ENTENDER LA LÓGICA DE CREAR ESTADOS 
---
###En p5.js, la función draw() se ejecuta en un bucle infinito (unas 60 veces por segundo). Si quieres que tu programa haga cosas distintas en momentos diferentes, necesitas una forma de decirle a draw() qué "pantalla" o comportamiento debe mostrar en cada momento. Eso es un estado.
